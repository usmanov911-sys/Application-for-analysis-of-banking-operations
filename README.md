# Приложение для анализа банковских операций

Приложение для анализа банковских транзакций из Excel-файла.  
Проект позволяет обрабатывать операции, рассчитывать доходы и расходы, формировать JSON-данные для веб-страниц, предоставлять аналитические сервисы и готовить отчеты.

## Возможности

Проект реализует следующие функции:

- загрузка и обработка транзакций из Excel-файла;
- нормализация дат, сумм, категорий и описаний операций;
- расчет расходов, поступлений и кешбэка по картам;
- формирование JSON-ответов для страниц:
  - Главная;
  - События;
- получение топ-5 транзакций по сумме платежа;
- аналитика расходов по категориям;
- выделение переводов и наличных в отдельный блок;
- получение курсов валют;
- получение стоимости акций;
- поиск транзакций по подстроке;
- поиск операций по телефонным номерам;
- поиск переводов физическим лицам;
- расчет потенциального кешбэка по категориям;
- расчет накоплений для «Инвесткопилки»;
- отчеты по тратам:
  - по категории;
  - по дням недели;
  - по рабочим и выходным дням;
- автоматическое сохранение результатов отчетов в JSON-файлы;
- покрытие ключевой логики тестами.

## Технологии

Проект написан на Python.

Основные библиотеки:

- `pandas` — обработка и анализ табличных данных;

- `pytest` — тестирование;
- `openpyxl` — работа с файлами `.xlsx`;
- `xlrd` — работа с файлами `.xls`.

## Подготовка данных
Файл с транзакциями должен находиться в папке data.

Например:

data/operations.xls

или:

data/operations.xlsx

Если ваш файл называется operations.xlsx, вы можете:
1. Переименовать его в operations.xls.
2. Либо указать путь к файлу при вызове функций из src.views.

Пример:
```python
from src.views import main_page

result = main_page(
    "2026-08-20 14:00:00",
    transactions_path="data/operations.xlsx"
)
```
#### Ожидаемые колонки в Excel-файле:

- Дата операции;
- Дата платежа;
- Номер карты;
- Статус;
- Сумма операции;
- Валюта операции;
- Сумма платежа;
- Валюта платежа;
- Кешбэк;
- Категория;
- MCC;
- Описание;
- Бонусы (включая кешбэк);
- Округление на «Инвесткопилку»;
- Сумма операции с округлением.

## Тестирование
Для запуска тестов выполните:
``` bash

pytest
```
#### Ожидаемый результат:

```text
19 passed
```
####  Тесты проверяют:

- приветствие в зависимости от времени суток;
- фильтрацию данных по датам;
- формирование топ-транзакций;
- расчет расходов и поступлений;
- группировку категорий;
- работу сервисов поиска;
- расчет «Инвесткопилки»;
- расчет кешбэка по категориям;
- формирование отчетов;
- сохранение отчетов в файлы.

## Пользовательские настройки

Настройки валют и акций находятся в файле:

```text
user_settings.json
```
Пример:

```json
{
  "user_currencies": ["USD", "EUR"],
  "user_stocks": ["AAPL", "AMZN", "GOOGL", "MSFT", "TSLA"]
}
```
Приложение использует эти списки для получения курсов валют и цен акций.

## Сервисы
В проекте реализованы дополнительные сервисы.
### 1. Выгодные категории повышенного кешбэка

Функция анализирует транзакции за выбранные год и месяц и возвращает потенциальный кешбэк по категориям.

Пример использования:
```python
from src.services import cashback_categories

result = cashback_categories(transactions, year=2026, month=8)
print(result)
```
Пример результата:

```json
{
  "Супермаркеты": 10.0,
  "Фастфуд": 5.0,
  "Топливо": 4.0
}
```
## Работа с внешними API
### Для получения курсов валют используется API Центробанка РФ:
```text
https://www.cbr-xml-daily.ru/daily_json.js
```
Для получения цен на акции используется Yahoo Finance.

Если внешние API недоступны, приложение не завершается с ошибкой, а возвращает корректные резервные значения.

Это позволяет обеспечить стабильную работу демонстрационных страниц даже без доступа к интернету.
